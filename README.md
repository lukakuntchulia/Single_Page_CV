# Single-Page HTML CV

A simple, semantically correct, and clean single-page CV project created using only HTML5, based on the project requirements from [roadmap.sh](https://roadmap.sh).

## 📌 Project Features

- **Semantic HTML5:** Uses proper HTML tags (`<header>`, `<main>`, `<section>`, `<article>`, `<address>`, `<footer>`) for structural integrity and accessibility.
- **SEO Optimization:** Includes essential Meta tags in the `<head>` section for search engine visibility.
- **Open Graph (OG) Tags:** Configured for proper preview cards when sharing links on social media.
- **Favicon:** Linked page icon in the document head.
- **Ready for CSS:** Structured cleanly so that CSS styling can easily be applied in future projects.

## 🛠️ Technologies Used

- HTML5

## 📁 Project Structure

- `index.html` — Main HTML file containing the CV content
- `README.md` — Project documentation and setup guide
